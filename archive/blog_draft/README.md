# Blog draft

`blog_draft.tex` is the proposed full version of the Free Systems post, built from `output/figures/` at the repository root
(relative path, so it recompiles after any pipeline run with `tectonic blog_draft.tex`). Structure follows
Letícia's results map of 12 September 2026; wording follows the Free Systems house style (findings as headings,
a bulleted list of results up front, rounded numbers with comparisons, figures referenced as "below", caveats
in one paragraph, robustness in a signposted appendix). `blog_draft_v1_academic.tex` is the first pass before
the style rewrite. Red bracketed notes are open items (citations, Ranqia method paragraph, validation numbers,
deputy register check).
